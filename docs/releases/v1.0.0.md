# Prism Clock 1.0.0

Prism Clock displays actual local time over an original continuously deforming metallic triangular surface. This first public release includes remote settings, an independent native preview, selected-Dream playback and complete offline credits.

## Upgrade guide

On Android 6/API 23 or newer with OpenGL ES 2.0 and DreamService support, install the signed `prism-clock.apk` with the guided installer:

```sh
python3 install.py --serial TV_IP:5555
```

The installer downloads the latest stable APK and checksum and asks before installation. For a downloaded file, use `python3 install.py --serial TV_IP:5555 --apk prism-clock.apk`. The package is `com.jeremykenedy.prismclock`, app version 1.0.0/code 1. Existing development installations signed with the original key can be updated in place; preserve their data and confirm saved settings. No migration, account, network permission, cache rebuild or service configuration is required.

Open Prism Clock from the TV launcher, choose a finish and clock options, then select Preview animation. Back returns Settings. Select the app through the TV's supported screensaver picker if wanted; installation does not change the selected Dream or timers. Host integration is separate and depends on the installed Toolkit/UI version.

Record your 11 settings before uninstalling or rolling back. Uninstall removes them. Android normally rejects a lower version code; there is no public earlier Prism release to recommend as a rollback target.

## Breaking changes

None; this is the first public release. Existing package identity, the unique production signing key and all 11 development preference keys/defaults are preserved.

## Major changes

- Continuously deforming original metal facets with silver, graphite, champagne and iridescent finishes.
- Actual local 12/24-hour time, optional seconds/date, three typography sizes and two continuous travel ranges.
- Facet scale, depth, motion and brightness controls, plus per-setting and whole-scene randomization.
- Remote-accessible offline NOTICE/full license, native settings/preview and a validated local host settings provider.

## Minor changes and fixes

- Shared mesh edges avoid seam-coordinate mismatches; bounded surface/clock lifecycle stops work on pause.
- A moving contrast field keeps the clock readable over changing reflections.
- Bundled native previews and actual verified captures replace placeholders.

## Verification and limits

Host geometry/options/clock checks, 100 percent owned Java line/branch coverage, 100 percent installer coverage, actual source formatting, privacy/artifact inspection and signed build pass. Exact API 34 native checks reached and scrolled the full license, selected Close, and verified Preview/Back and bound Dream/Back. An in-place API 34 update retained 11 exposed preferences.

The original-key signed APK is 127,947 bytes, SHA-256 `edbf475c4a2b253ccc069adaee8cac2cbba4d16b5579d5299e2e2d1bdaa21fd5`. Physical AFTDEC012E/API 30 checks exercised the maximum silver preset for 40 seconds before production samples of 24.59 and 24.67 actual presents per second. The minimum graphite preset ran as the selected non-test Dream. Normal-speed eight-second playback confirmed coherent deforming facets and a legible drifting clock. Native Menu leaves Preview active, Back returns Settings and Home exits. Original preferences, protected system state, UI protection and the original selected Dream were restored.

Physical pre-update values were unavailable through the older provider, so only the 11 post-update values are covered by physical restoration. The short pacing sample has limited headroom and does not establish thermal endurance. Native 4K, automatic idle/reboot and other physical models remain untested. The scene is rendered artwork, not filmed material.
