# Prism Clock 1.1.0

## Major changes

Show clock can now hide all time/date text and its backing while the original
metal surface keeps moving. It defaults to On and is independent of per-scene
randomization. The app-owned schema exposes the new boolean for hosts.

## Upgrade guide

Update from the public 1.0.0 release using the signed APK or the existing guided installer:

```sh
python3 install.py --serial YOUR_ADB_SERIAL
```

Updates preserve the package, unique signer and eleven existing choices.
Android versionCode is 4. The APK needs API 23 and OpenGL ES 2; declared requirements
are not a universal compatibility claim. No permissions or runtime network
requests are added.

No new dependencies, environment variables, migrations, cache clearing, preference reset or TV reboot are needed. Open native settings, turn Show clock off, then open Preview to check the result. Hosts consuming the settings schema should support the new boolean with default true and randomAllowed false.

For a temporary rollback, choose another screensaver while keeping Prism's settings. Android may reject an in-place downgrade to an older production version code. Uninstalling to reinstall an older APK deletes local choices, so save those choices first.

## Breaking changes

None. Runtime minimums, existing settings, rendering design and default clock visibility are unchanged. The new field is additive.

## Minor changes and fixes

Current physical screenshots and settings provenance document clock-on and clock-off behavior. The independent clock switch stays unchanged when scene randomization is enabled.

## Verification and limits

The signed native artifact is 127,947 bytes, SHA-256
`6d1a3204ca648033c3c0c1d68adcceb29e90ed1ff61ec24b7f65e1326b7621e8`.
Actual API 28 remote ON/OFF and Preview/Back passed with all settings retained.
The equivalent earlier 1.1 runtime passed natural five-minute non-test Dream,
emulator randomization, process-death persistence and lifecycle checks.
See [verification](../verification.md) for exact artifact boundaries.

Measured API 28 default rendering is about 17 to 18 compositor presents/s. The
original mesh, shaders and rendering design are unchanged. This release adds a
clock option; it does not claim faster rendering, thermal endurance, native 4K,
reboot durability or untested-device support.

Download the APK and matching checksum from the verified release. The guided
installer and Toolkit use same-package replacement and do not change the selected
Dream or TV timers. Both ecosystem pins must use the actual published artifact.

See the [tagged configuration guide](https://github.com/jeremykenedy/prism-clock/blob/v1.1.0/docs/configuration.md) and [changes from v1.0.0](https://github.com/jeremykenedy/prism-clock/compare/v1.0.0...v1.1.0).
